# 品牌设计规范 · 小咕（Study desktop）

> 版本：v0.1（初稿，待评审）｜ 日期：2026-08-10
> 本文档是 Study desktop 品牌与视觉工作的"宪法"，锁定决策、指导后续所有 UI 改造。

## 一、产品定位（已决策）

- **骨架：私人教务** —— 可靠、有计划、功能不设门槛，把课表/复习/任务/笔记安排得明明白白。
- **气质：学习伙伴** —— 有温度、会庆祝、不打扰，像一位"深夜陪你自习的学长/学姐"。
- **一句话**：**「一个有温度的私人教务」**。
- 游戏化与吉祥物只是**可选玩法/伙伴层**，绝不与核心功能深度绑定（避免用户流入变窄）。

## 二、吉祥物设定：小咕

| 项 | 设定 |
|---|---|
| 名字 | **小咕**（Xiǎo Gū）——取自猫头鹰叫声"咕"，拟人化称呼，简洁有记忆点 |
| 身份 | 私人教务 × 伙伴气质的化身 |
| 性格 | 沉稳博学、偶尔呆萌；深夜陪伴；**不催不闹** |
| 造型 | 扁平矢量猫头鹰：几何化圆头、大眼、小喙、圆润翅膀；主色 靛蓝 + 琥珀 |
| 画风规范 | 统一圆头线条（stroke 4px @ 64px 基准）、2-3 阶同色系渐变、无多余阴影；拒绝写实/3D/照片 |

**表情系统**（初版 6 个）：
常态专注（默认，呼吸动画）｜开心庆祝（完成番茄/打卡/清空任务）｜困倦（深夜时段可选）｜惊讶（到点提醒）｜歪头（到期卡片堆积时的轻提醒）｜思考（AI 助手工作中）

**使用铁律**（防止"Clippy 效应"）：
1. 小咕不承载核心功能——关闭小咕不影响任何能力。
2. 默认低调：静止时仅小幅呼吸；不自动弹出打扰。
3. 触发点有限且短暂：仅庆祝/轻提醒时出现，2-3 秒后消失。
4. 尊重 `prefers-reduced-motion`；设置里提供"关闭小咕动画与互动"。

## 四、字体与图标

### 字体
- 正文：维持系统 CJK 栈（PingFang SC / Microsoft YaHei / Segoe UI），保证本地无加载成本。
- 品牌字体：标题/数字引入一款开源 Display 字体（如 Outfit / Sora，fontsource 包，仅拉丁字符，体积 <100KB）；中文标题用字重 + 字距控制。
- 字号层级：`12 / 13 / 14 / 16 / 18 / 22 / 28`，标题加 `letter-spacing: -0.02em`。

### 图标
- 功能图标：**lucide-react**（已依赖），不新增图标库。
- 模块图标：lucide + 模块色（侧栏激活态使用模块色，形成记忆锚点）。
- **emoji 退役计划**：约 700+ 处 emoji 分三批替换——① 空状态/引导（P1）② 标题/按钮/Toast（P2）③ 通知/提示性文案（P3）。保留少量作为"文案语气词"（如 ✅ 完成提示）而非功能图标。

## 六、小咕互动规格与难度（评估版）

| 级别 | 能力 | 技术实现 | 难度 | 工期 |
|---|---|---|---|---|
| L1 | 点击反馈：眨眼/摇摆/表情/气泡 | React state + CSS keyframes（SVG 组件） | ★☆☆☆☆ | 0.5–1 天 |
| L2 | 拖拽甩动：带物理感（摆锤/弹簧） | Pointer Events + CSS transform + requestAnimationFrame 弹簧 | ★★☆☆☆ | 1–2 天 |
| L3 | 桌面悬浮伙伴：独立常驻窗口、可拖、点击穿透、位置记忆 | 复用 widgetWindow 模式（transparent/alwaysOnTop/skipTaskbar）+ setIgnoreMouseEvents | ★★★☆☆ | 2–4 天 |
| L4 | 语音/智能互动 | Web Speech TTS 或 Edge-TTS + 现有 AI 通道 | ★★★★☆ | 后续 |

**结论**：L1+L2 成本很低且亮点明显，建议作为 P1 品牌渗透的一部分（应用内"可玩的小咕"）；L3 桌面伙伴是独立可选项，放 P2 后评估（用户无感用户可完全关闭，符合铁律）。

**技术约束**：动画只用 `transform`/`opacity`（GPU 合成，不触发重排）；不引入重型动画库；尊重 `prefers-reduced-motion`；拖拽与点击用位移阈值（>6px 视为拖）区分。

## 八、图标定稿（2026-08-10）

**最终方案**：方形铺满图标 = 原创深蓝紫夜空渐变 + Twemoji 🌙 标准金色月牙 + 2 颗原创白色四角星 + Google Noto 猫头鹰（棕身奶油脸）+ 原创暗红封面/米白内页厚书。

**素材出处与许可（必须保留署名）**：
- 猫头鹰主体：**Google Noto Emoji 🦉** — Apache-2.0（可商用，无署名强制，保留出处更佳）
- 金色月牙：**Twemoji 🌙** — CC-BY 4.0（twitter/twemoji，需署名）
- 夜空渐变 / 四角星 / 厚书 / 构图：本项目原创

**生产链路**：
1. `node scripts/gen-icon-final.js` → 生成 xiaogu-final.svg / xiaogu-tray-final.svg
2. Electron 无头渲染（每进程一次 loadFile）→ xiaogu-final-512.png / xiaogu-tray-final-512.png
3. nativeImage.resize → 各尺寸 PNG；Node 组装多尺寸 .ico
4. 应用引用：窗口/安装包 → `assets/brand/xiaogu-icon.ico`；托盘 → `xiaogu-tray.png`；PWA → `public/icon.png`

**遗留（可选）**：16px 极小尺寸可单独出"极简版"提升清晰度；小咕表情/互动系统（L1/L2）留待 P1 后推进。
