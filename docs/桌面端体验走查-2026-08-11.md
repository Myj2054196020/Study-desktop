# 桌面端体验走查 · 2026-08-11

> 方法：通读 electron 主进程（生命周期 / 托盘 / 全局快捷键 / 启动 / 窗口行为），逐项核对体验；对托盘图标做了 16px 实渲染对比。

## 一、现状核对（已达标）
| 项 | 行为 | 评价 |
|---|---|---|
| 关闭按钮 | `close` 事件 preventDefault → 隐藏到托盘，应用常驻 | ✅ 托盘应用标准行为 |
| 桌面图标二次点击 | 单实例锁 + `second-instance` → 显示主窗口 | ✅ 已修复早期"点了没反应" |
| 开机自启 | 设置里 `autoStart` + `startHidden`，传 `--hidden` 启动隐藏 | ✅ 首次运行始终显示 |
| 全局快捷键 | Ctrl+Shift+F/P/T（搜索/番茄/快捷任务） | ✅ |
| 托盘菜单 | 显示主窗口 / 开始番茄钟 / 退出；双击显示窗口 | ✅ |
| 单实例 | requestSingleInstanceLock | ✅ |
| 最小窗口 | 900×600 | ✅ 窄窗不会真正触发 |

## 二、本轮改进（已落地）
1. **首次最小化到托盘提示**：第一次点关闭隐藏时，系统通知一次「已最小化到托盘。双击托盘图标可重新打开；右键托盘图标可选择退出。」——避免新用户以为"退出失败/应用卡死"。
2. **全局快捷键注册失败日志**：`globalShortcut.register` 返回 false 时打印日志，便于排查被占用。
3. **托盘图标对比结论（未改）**：实渲染 16px 对比，`xiaogu-tray.png`（旧）清晰识别为猫头鹰；`xiaogu-tray-final.png`（场景版，书+猫头鹰）在 16px 下识别为"文件夹"——托盘场景**保持原图标**，不强行升级。
