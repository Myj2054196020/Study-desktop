## 四、关键洞察

1. **"全能学习工作台"是空白赛道**：14 个候选中，只有 StudyDesk（6★，无复习体系）和 StudyHelper（0★，多用户 LMS）与本项目同赛道。本项目在"本地优先 + 复习卡片 + 课表 + PDF + 知识图谱 + AI + 错题本"的组合上独一无二，但**未发布、无社区**是最大短板。
2. **每类竞品都有一个"纵深王者"**：复习→Anki（29.6k★，FSRS 已是标配）；知识管理→Logseq（原生图谱）；阅读→koodo-reader（27.8k★）；时间管理→super-productivity（21.2k★）。它们的共同点是**把一件事做到极致 + 插件生态**。
3. **FSRS 已成为行业标准**：Anki、rem、Brainy、StudyHelper 全部采用 FSRS 调度；本项目已用 ts-fsrs，方向正确，可对标 Anki 的调度参数可视化。
4. **AI 是差异化但未普及**：仅 Brainy（已死）、AFFiNE/AppFlowy（通用 PKM）和 StudyHelper 深度集成 AI；本项目"AI 助手 + 错题自动入册 + 复习卡生成"已领先同类学习桌面。
5. **移动端是普遍短板/机会**：同赛道项目几乎都没有手机端，AnkiDroid/Joplin 靠独立 App。本项目已有 PWA 基础，是低成本的移动扩展点。
6. **可借鉴的高价值特性**：
   - StudyDesk：锁屏专注（全屏倒计时防分心）、专注花园游戏化、上下课真实铃声、桌面摆件
   - rem：agent-first 采集（AI 生成草稿→人工批准→进复习计划）、终端 CLI 复习、Git 同步
   - Anki：调度参数可视化/统计深入、插件生态、多端同步
   - koodo-reader：专业阅读体验（TTS、翻译、双页、深色）
   - super-productivity：任务与番茄的深度绑定、时间线视图
   - StudyHelper：AI 学期学习计划、学习会话模式（due/random/wrong 过滤）、审计日志

## 五、对优化方向的启示（供讨论）

- **A. 广度已领先 → 做纵深**：把 1-2 个模块打磨到"可替代专业工具"水准（如复习卡片对标 Anki 的统计可视化、PDF 对标 koodo-reader 的阅读体验）。
- **B. 补齐高分项**：锁屏专注、专注花园、任务×番茄深度绑定、调度参数可视化。
- **C. 发布与社区**：发布到 GitHub 开源（MIT 已具备）是获得反馈与 stars 的前提。
- **D. 移动端 PWA 完善**：低成本覆盖手机端。
- **E. AI 纵深**：AI 学期计划/学习会话模式（StudyHelper 已验证的形态）。
