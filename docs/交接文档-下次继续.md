## 三、常用命令（在 E:\code\learning-desktop）

| 命令 | 作用 |
|---|---|
| `npm run dev` | 开发模式（编译主进程 + Vite + Electron） |
| `npm run typecheck` | TS 类型检查 |
| `npm run build` | 构建（tsc 主进程 + vite 前端） |
| `npm run smoke` | 数据层冒烟 50 项 |
| `npm run test` | 单元测试 13 项 |
| `npm run package` | 打包 NSIS 安装包（联网，需镜像 + CSC 变量） |

## 四、关键路径

- 主进程：`electron/main.ts`（窗口/托盘/定时提醒/IPC 注册）
- 数据库：`electron/ipc/database.ts`（DataStore，JSON 持久化）
- 前端入口：`src/App.tsx` → `src/components/layout/AppShell.tsx`
- 全局状态：`src/stores/`（AppContext/TaskContext/ChapterContext/PomodoroContext/ReflectionContext）
- 样式：`src/index.css`（单文件，模块注释分区）
- 品牌资产：`assets/brand/`（小咕 SVG/PNG/ICO）
- 测试 mock：`E:\tmp\reader-test\preload.cjs` 等（端到端驱动用）
- 文档：`docs/`（产品方案、走查记录、发布指南、工作经验沉淀）

## 五、发布流程（重要，详见 docs/工作经验沉淀.md 第三节）

1. 本地打包 → 2. git tag + push GitHub（Actions 自动构建）→ 3. 公开 release + 核对 exe asset → 4. Gitee 同步代码 + 分卷 → 5. README 下载链接 → 6. 提醒用户传百度网盘。

**关键凭证/状态**：
- GitHub：gh CLI 已 OAuth 授权（完整权限）。注意用户级环境变量 `GH_TOKEN` 是只读，push 前 `Remove-Item Env:GH_TOKEN`。
- Gitee：需要有效私人令牌（用户提供；历史令牌已重置，用时向用户要）。
- 百度网盘：用户手动上传，链接由用户提供。
