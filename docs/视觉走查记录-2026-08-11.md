## 二、深色主题走查（2026-08-11 追加）

> 方法：无头 Electron 切到深色主题，14 页全量截图评审。

### 发现并修复

1. **热力图浅色格子**（已修复）
   - 问题：热力图色阶硬编码为浅色系（`#F1E8D3`…`#D9922E`），深色主题下"空状态"格子也是亮奶油色，看起来像"全部已打卡"，刺眼且误导。
   - 修复：色阶改为 CSS 变量 `--heat-0…4`，深色主题覆盖为 深蓝 → 琥珀 的夜间色阶（空=深蓝 `#232B48`，满=琥珀 `#D9922E`）。
   - 验证：计算样式探针确认浅色 `rgb(241,232,211)` → 深色 `rgb(35,43,72)`。

2. **图表网格线 / 待办扇区 / Tooltip 硬编码浅色**（已修复）
   - 问题：recharts `CartesianGrid stroke="#e5e7eb"`、饼图待办扇区 `#E5E7EB`、默认白色 Tooltip，在深色下过亮刺眼。
   - 修复：网格线与扇区改用 `var(--border)`；Tooltip 加主题化 contentStyle（surface 底 / border 描边 / 主题文字色），浅深通用。
