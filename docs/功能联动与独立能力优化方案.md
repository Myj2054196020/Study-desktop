# 功能联动与独立能力优化方案

> 日期：2026-08-11 ｜ 目标：让软件"像一套系统"而非"16 个孤岛"，同时保证每个模块**独立可用、不绑架用户**。
> 原则（沿用你定的底线）：不影响无需求用户；不过度吸引有需求用户；联动是"顺手可走的路"，不是"必经的门"。

---

## 一、定位

学习工作台的核心不是功能多，而是**一条条能被日常自然走通的习惯回路**：

```
章节学习 → 番茄专注 → 复盘心得 → 生成卡片 → 每日复习 → 错题沉淀 → 统计回看 → 再次学习
```

联动要做的是：让回路中的每一步，在**当前界面就能看到下一步的入口**，而不是靠用户记住"哦我要去别的页签点一下"。

---

## 三、本轮新增联动（已落地）

1. **章节 → 番茄专注**：章节详情页新增「番茄专注这一章」，一键把该章绑定为专注任务并进入番茄钟，结束即可复盘 → 心得。
2. **复习卡 → 错题本**：复习时翻到答案，若没记住，点「这题没记住？加入错题本」直接把这张卡沉淀为错题，继续复习不打断。
3. **书架批注 → 卡片 / 心得**：阅读器批注旁新增「转卡片」「存心得」，读到好句子随手沉淀，不再只能留在书架里。
4. **阅读计时 → 学习统计**：书架「计时」结束时写入独立阅读记录，阅读时长并入今日学习分钟 / 热力图 / 周报（不污染番茄钟计数）。
5. **阅读器升级**：图片/PDF 支持拖动平移、滚轮缩放（光标为中心）、双击切换 100%、适应窗口、+/−/0 快捷键；工具栏全部可用（翻页、书签、批注、转卡片、存心得）。

## 五、独立性保障（联动不绑架）

每个模块保持**独立可用**，联动只是"可选的捷径"：

1. **独立入口**：所有模块都在侧栏有固定入口，不依赖从别的模块跳转才能到达。
2. **独立空状态**：每个模块空状态给出"从零开始"的引导（如卡片页无数据时引导从章节生成）。
3. **独立数据闭环**：番茄钟没有任务也能专注；卡片没有章节也能创建；心得不绑定章节也能写；错题不绑章节也能记。联动字段（chapterId/subjectId）全部可选。
4. **可关闭**：所有自动化联动（自动转卡、自动入错题本、收尾提醒）都有设置开关，默认保守。
5. **数据可迁移**：任一模块的数据可单独导出（卡片 CSV、Markdown 资料库、整体备份），不被其他模块绑架。

## 六、完成标准

- 用户从"章节"出发，能在 2 次点击内触达"专注/复习/沉淀"任一动作；
- 用户从"书架/视频"出发，能把读到的内容沉淀进卡片与心得；
- 所有联动均可跳过、可关闭；无任何弹窗强制打断；
- 统计能反映"专注 + 阅读 + 复习 + 错题"的完整投入。
