# Study desktop 整体改造方案 · 高级感 V2

> 日期：2026-08-11 ｜ 目标：从"换底色"到"真正动刀"，让界面有高级感、有品牌识别、摆脱模板感

## 一、诊断：为什么现在只是"换了个底色"

| 现状 | 问题 |
|---|---|
| 布局仍是"标题栏 + 左侧栏 + 卡片网格" | 最通用的后台模板结构，信息架构没变，怎么配色都像换皮 |
| 卡片全部等宽白卡 + 细边框 | "Dashboard 模板"观感 |
| 背景是纯色 | 缺少材质/层次/氛围 |
| 动效零散 | 没有系统化的"活"的感觉 |
| 组件风格不统一 | 按钮/输入/弹窗/表格各自为政 |

**结论**：高级感 = 结构设计 + 材质 + 层次 + 动效的统一体，配色只是最后一步。

## 二、设计理念

**"一间深夜亮着台灯的书房"**——功能是"学习工作台"，但氛围是安静、温暖、有陪伴（小咕）。所有改动都围绕这个意象。

## 三、改造四大板块

### 板块 1 · 布局架构（最大的"动刀"）
1. **标题栏 → 品牌栏**：左侧小咕 + 产品名；中间嵌入**全局搜索框**（不再是纯弹窗）；右侧快捷 + 窗口控制。沉浸、可拖拽区合理。
2. **侧边栏 → 导航栏**：
   - 半透明毛玻璃质感（backdrop-blur）
   - 分组更清晰（学习/专注/洞察/系统，带小标题）
   - 激活项：圆角胶囊 + 模块色 + 左侧小圆点 + 渐变底
   - 底部品牌卡：小咕 + "深夜自习室" + 当前连续打卡/专注
3. **内容区**：max-width + 更大留白；页面标题统一（模块色小图标 + 大标题 + 副文案）。

### 板块 2 · 视觉质感（高级感核心）
4. **背景系统**：浅色=奶油纸 + 极淡噪点 + 角落暖光；深色=夜空 + 星尘噪点（CSS 渐变 + data-URI 噪点，不引图片）。
5. **卡片体系**：阴影三级（悬浮/默认/按压）；圆角分级（hero 20 / 卡片 14 / 小组件 10）；hover 上浮 + 顶部边缘高光。
6. **按钮体系**：主=琥珀渐变 + 柔和投影；次=描边；危险=红；统一 focus ring 与按压反馈。
7. **图表统一品牌色**（已完成大半）。

### 板块 3 · 动效系统（"活"的感觉）
8. 页面切换过渡（已有）→ 卡片入场 stagger；统计数字滚动。
9. 按钮/卡片 hover 与按压统一。
10. 小咕 L1（已有）→ 升级 L2 拖拽甩动。

### 板块 4 · 组件级统一（设计语言）
11. 表单控件（输入/下拉/开关/标签/单选）统一。
12. 弹窗/抽屉统一圆角与动效。
13. 列表/表格统一间距、行 hover、空状态（小咕，已有）。

## 五、原则
- 所有改动基于现有 token（深夜自习室），不引入新框架/图片
- 每阶段保持可构建、可运行
- 小咕互动遵循"低调、可关闭、不打扰"
- 一次只动一块，避免大面积重做失控
