# 会话摘要：Study desktop 学习工作台（2026-08-03）

## 一、对话主题
在 Windows 环境（E:\code）用 Codex 从零构建并持续迭代「桌面端本地学习管理应用」Study desktop：Electron + React + TypeScript + Vite；本地优先、私人使用、可一键分享。

## 二、关键决策与用户偏好
- 应用名：Study desktop；主目标 Windows。
- 使用场景：日常系统学习；需要多科目/多目标维度；无需云同步；不需要数据加密；私人使用，不要求 GitHub 发布（已预留 CI 工作流）。
- AI：默认预置 DeepSeek 接口（https://api.deepseek.com，模型 deepseek-chat），用户已配置 API Key；支持任意 OpenAI 兼容接口。
- 存储：JSON 文件方案（用户数据目录 + 自动备份 + 文件夹同步），放弃 better-sqlite3 以规避 Windows 原生编译风险。
- 环境约束（对后续会话重要）：本 CLI 命令行会过滤双引号、美元符与反引号；Set-Content 会生成 BOM（需运行 scripts/strip-bom.js）；electron-builder 下载需镜像源（ELECTRON_MIRROR、ELECTRON_BUILDER_BINARIES_MIRROR = npmmirror）；单引号 here-string 内容须多行书写。
