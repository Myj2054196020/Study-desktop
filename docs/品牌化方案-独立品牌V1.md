## 〇、结论先行（TL;DR）

1. **现状诊断**：质感、布局、动效已达标，但视觉语言仍是"通用后台模板"——等宽卡片、统一 lucide 图标、图谱硬编码配色、空白首屏、通用占位文案。这是"精化"而不是"品牌"的原因。
2. **品牌母题提案**：**「台灯之光」**。深夜自习室的"灯"是本项目最强的可占有意象：它同时解释配色（琥珀=灯光）、场景（深夜书房）、伙伴（小咕坐在灯下）、习惯（灯不灭=不中断）。所有视觉动作围绕"光"展开。
3. **参考拆解**：matte / amie / Linear / Duolingo / Forest / Obsidian / Heptabase 各取一个可迁移动作，本土化为我们的语言。
4. **两条线**：P5 品牌层（视觉母题落地）→ P6 内容层（章节/知识图谱可配置化，本轮只出方案不改代码）。
5. **小咕互动**：拖拽范围限制 + 拖动反馈已在 `a6e6c5a` 修复并提交；下一档做"语境互动"。

## 一、诊断：为什么还不是"品牌"（证据在代码与截图里）

| # | 观察 | 证据 | 定性 |
|---|---|---|---|
| 1 | 全站卡片等宽、等圆角、等阴影 | index.css 卡片体系；截图确认"卡片布局高度统一" | 模板感：像组件库拖出来的 Dashboard |
| 2 | 图标全部 lucide 线性库，无品牌专属符号 | 侧栏/标题/按钮全是 lucide | 与任何后台模板无异，无识别性 |
| 3 | 知识图谱配色与品牌脱节 | `KnowledgeGraph.tsx` 硬编码 `#22C55E` / `#94A3B8` / `#374151` | 最典型的"AI 味"来源：色板没有进入图谱 |
| 4 | 首屏/空状态空白 + 通用文案 | 截图：首页主区空白；"今天还没有必做事项"等占位 | 品牌叙事缺失：用户看到的第一个画面是"空" |
| 5 | 小咕出现 3 处但语境割裂 | 侧栏 logo / 顶部头像 / 右下浮窗，造型同源但无叙事 | "贴图"感：吉祥物没有成为故事的一部分 |
| 6 | 深色模式=换皮 | `[data-theme='dark']` 只是色值替换，无光晕/层次 | 是"深色皮肤"不是"夜间书房" |

**结论**：品牌 = 一个可占有的视觉母题 + 全站一致的执行纪律。我们现在有纪律（token、圆角、动效），但没有母题。

## 二、参考项目拆解（每项只取一个可迁移动作）

| 项目 | 它做了什么 | 一句话动作 | 我们的本土化 |
|---|---|---|---|
| **matte.app** | 动效/阴影/色彩全部"命名"，spring 缓动就是品牌签名 | 让"动效参数"成为品牌的一部分 | 已有 `cubic-bezier(0.34,1.56,0.64,1)` spring——把它命名为"小咕跳"，全站统一用它 |
| **amie.so** | 单一情感色（rose）一次只出现在一处；分层阴影代替边框 | 克制：一个情感色 + 阴影表达层次 | 琥珀=我们的 rose，每屏只点亮一处"强琥珀" |
| **Linear** | 用"表面色分组"代替留白；自定义主题生成器 | 信息密度与可定制即品牌 | 侧栏分组已是毛玻璃；后续做"主题微调"（色相偏移） |
| **Duolingo** | 吉祥物=习惯引擎：streak/提醒绑定到行为节点，有表情有脾气 | 吉祥物绑在"行为"上，不是装饰 | 小咕在完成番茄/打卡/到期时出现 2–3 秒（已有 L1），升级为"台灯场景" |
| **Forest** | 把核心行为（专注）变成一个视觉隐喻（种树） | 隐喻即品牌：一个意象解释一个核心功能 | 番茄钟 = "台灯点亮"：专注中整页光锥加强，结束光柔和 |
| **Obsidian** | 图谱可过滤、按 path/tag 分组着色、多视图 | 可配置带来"拥有感" | 章节/图谱可配置化（见第四节） |
| **Heptabase** | 白板卡片 + 卡片字段化 + 多上下文复用 | 结构化卡片是知识图谱的地基 | 章节模板字段化（P6） |

**综合原则**：
1. 一个母题，讲一个故事（我们：灯）。
2. 一个情感色，一次只亮一处（我们：琥珀）。
3. 吉祥物绑行为，不绑装饰（小咕只出现在"有原因"的时刻）。
4. 隐喻解释核心功能（番茄钟=台灯点亮）。
5. 可配置 = 用户拥有感（章节/图谱）。

## 三、品牌提案：台灯之光

### 3.1 世界观（一句话）
> **「深夜书房里，小咕为你留了一盏灯。」**

- 三个支柱：
  - **书房**：私人教务，可靠、有计划（骨架不变）。
  - **灯**：专注氛围，温暖、安静（视觉母题）。
  - **小咕**：陪伴，不催不闹（伙伴层）。
- 习惯隐喻：**「灯不灭」**——连续打卡/专注 streak 的表达。不学 Duolingo 用"威胁保 streak"，我们用"台灯还亮着，小咕还陪着你"，符合小咕"不催不闹"的设定，且本土化、可翻译成画面（一盏长明的灯）。

### 3.2 视觉母题落地清单（P5 具体改动）

| 位置 | 现状 | 改动 |
|---|---|---|
| 背景 | 奶油纸/夜航蓝 + 噪点 | 页面角落一盏**暖光**（径向渐变）：浅色=奶油纸上的台灯光斑；深色=夜航蓝上的光锥 + 星尘（已有噪点，叠加光） |
| 卡片 | 顶部 1px 边缘高光 | 升级为**"受光面"**：高光在 hover 时变亮、位置轻微上移，像被灯照到 |
| 主按钮/激活态 | 琥珀渐变 + 投影 | 增加 `--glow` 光晕 token（琥珀 15–20%），但**每屏只亮一处**（amie 纪律） |
| 番茄钟 | 普通页面 | 专注中：整页光锥加强（台灯点亮）；结束：光柔和。隐喻=Forest 的树 |
| 小咕浮窗 | 底部固定 | 加一圈极淡琥珀 halo（坐在灯里）；**拖拽时 = 拖着一盏小灯**（halo 跟随） |
| 侧栏品牌卡 | "深夜自习室·学习工作台" | 升级为**"灯下的小咕"小场景**：有到期卡片/未完成必做时灯芯微亮提示，全部完成时小咕翻开书、灯更亮（Duolingo 式行为反馈，2–3 秒） |
| 知识图谱 | 硬编码绿/灰 | 改品牌 token：琥珀=已掌握、靛蓝=进行中、灰=未开始；按学科分组时用低饱和模块色（为 P6 可配置打底） |
| 空状态/首屏 | 空白 + 通用文案 | 小咕坐在灯下看书的插画 + 一句话 + 一个下一步按钮（复用现有 34 处空状态改造计划的品牌叙事） |

### 3.3 色彩纪律（不是换色，是"收敛"）
- **保留 14 模块色**作为导航记忆锚点，但使用率下调：模块色只在 3 处出现（侧栏激活胶囊、页面标题图标、图谱分组），页面其余部分回归中性（奶油/夜航蓝 + 琥珀）。
- 新增 token：`--glow`（琥珀光晕）、`--light`（光斑高光）、`--halo`（小咕光环），深浅色各一套。
- 图谱/图表统一走品牌 token，消灭散落的 `#22C55E` 这类硬编码。

### 3.4 排版与文案调性
- 排版：保留 Outfit（数字/拉丁展示）+ 系统 CJK；统计数字、番茄钟数字用 Outfit + `tabular-nums`；中文标题统一加字距 `-0.02em`、标题字号分级更明显（28→34 一级）。
- **文案调性表**（品牌声音=小咕语气，温和不卖萌过度）：

| 场景 | 现状 | 改为 |
|---|---|---|
| 每日必做为空 | 今天还没有必做事项 | 来定今天的第一件事吧，小咕帮你盯着 |
| 无到期卡片 | 暂无到期卡片 | 卡片都复习完啦，今晚可以睡个好觉 |
| 连续打卡 | 连续打卡 N 天 | 灯已亮 N 晚 · 连续打卡 |
| 专注开始 | 开始专注 | 点亮台灯，开始专注 |
| 专注结束 | 完成 | 这一盏灯灭了，小咕给你记上一笔 |
| 到期提醒 | 有 N 张卡片到期 | N 张卡片到期了，灯还亮着，趁热复习 |
| 首次进入首页 | 空白 | 欢迎来到你的深夜书房 —— 小咕在这里 |

> 原则：**保留少量 emoji 作为语气词（✅🔖），功能图标一律 lucide**；文案不喊口号、不玩梗过度，符合"沉稳博学、偶尔呆萌"。

### 3.5 结构差异化（打破等宽卡片）
- 首页 hero（今日行动台）已有通栏 → 内容卡分**主/次/微**三级：主卡（通栏+受光面）、次卡（标准）、微卡（小组件，如侧栏场景卡）。
- 圆角/阴影分级已在 P2 落地，P5 只需让"受光面"随层级变化，形成明确的视觉节奏。

### 3.6 小咕互动 L2.5（回应"拖动没有互动感"）
- **已修复并提交（a6e6c5a）**：拖拽范围限制 ±180/±140；拖动时小咕跟随指针 + 放大反馈（原来指针捕获在 SVG 内部导致"小咕没动"）；松手弹簧归位 + 甩动；点击与拖拽已区分。
- **下一档（P5，成本 ★☆☆–★★☆，纯 CSS/React state，无新依赖）**：
  1. 拖拽时小咕**视线跟随**指针（歪头/眼睛偏移）——"它在看你拖它"。
  2. 拖到特定模块区域松手 → **语境气泡**（拖到番茄钟→"要开始专注吗？"；拖到任务→"记一件必做？"）。
  3. 释放阻尼调参（归位更自然）。
- L3 桌面悬浮伙伴（独立常驻窗口）仍放后面评估，保持"伙伴层不承载核心功能"铁律。

## 四、章节 + 知识图谱可配置化（先出方案，不改代码）

### 4.1 现状
- **章节**：已有模板系统（标准/公式定理/错题/空白，偏数学）+ 设置里可加自定义模板 + 批量导入 .md 文件夹。数据结构已有 `subjectId` / `parentId` / `studyMinutes`。
- **图谱**：cytoscape + dagre，节点=章节，按 parentId 连边；**无过滤、无分组着色、无布局切换、配色硬编码**。

### 4.2 参考（对应用户"数学系量身定做→高度可定制"）
- **Obsidian Graph**：搜索过滤、标签/附件开关、按 path/tag 分组着色、多视图预设、节点形状/大小映射。
- **Logseq**：命名空间 + 属性过滤、图谱层级。
- **Heptabase**：卡片字段化、同一卡片多上下文复用（一张定理卡同时出现在"数学分析"和"错题"里）。
- **Anki/FSRS**：调度参数可视化（卡片到期曲线）——我们已有 ts-fsrs，可做"下次复习时间分布"展示。

### 4.3 落地建议（分阶段）
| 阶段 | 内容 | 依赖 |
|---|---|---|
| A（P6-1） | 图谱分组着色（按学科/标签/完成状态）+ 过滤器（搜索、只看某学科）+ 布局切换（dagre LR / 自上而下 / cose） | 数据结构已具备，纯 UI + 配置持久化 |
| B（P6-2） | 章节模板**字段化**：标题/学习目标/知识点/例题/易错点/总结 可增删字段；按学科预置模板库 | 模板已有，扩展存储结构 |
| C（P6-3） | 图谱视图预设（保存/切换多套视图）+ 节点大小映射学习时长 + FSRS 到期曲线可视化 | 依赖 A |
| D（远期） | 章节/卡片"多上下文复用"（Heptabase 式） | 需要数据层重构，放远期评估 |

> 原则：**先 UI 可配置（A），再数据可配置（B/C/D）**；配置只影响展示，不改变核心流程，保证"不影响无需求的用户"。

## 附 · 品牌精化 C（2026-08-11 已落地）

> 动效签名「小咕跳」：把 spring 缓动变成品牌签名。

1. **定义动效令牌**：`--ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1)`（「小咕跳」，带一点回弹）、`--ease-soft`、`--dur-fast/-med/-slow`，收敛全站散落的魔法数字。
2. **应用到品牌时刻**：
   - 卡片悬停：主卡片（统计/番茄/章节/心得/书架/模板）hover 上浮 2px + 阴影加深，`transform` 走 spring——"跳起来"的品牌手感；
   - 首页 dash-card、侧栏导航项 hover 微移、主按钮 hover 上浮 / active 按压回缩，统一 spring/soft；
   - 弹窗入场、小咕拖拽/弹跳改用 `--ease-spring` 令牌（原已用该曲线，现纳入命名体系）。
3. **原则**：动效只用于"反馈时刻"，不堆砌、不喧宾；`prefers-reduced-motion` 降级保持不变。
